== Step 1: Copy the model onto /mnt/models

`/opt/app-root/src` and `/mnt/models` are both mounted in `self-healing-workbench`, and they are different volumes. A symlink on the workbench home directory would not be visible to the predictor. Copy the files onto `model-storage-pvc`:

[source,terminal]
----
oc exec -n self-healing-platform self-healing-workbench-0 -c self-healing-workbench -- bash -c '
  set -euo pipefail
  src=/opt/app-root/src/models/parasol-anomaly-detector
  dst=/mnt/models/parasol-anomaly-detector
  test -f "$src/model.pkl"
  mkdir -p "$dst"
  cp -a "$src/." "$dst/"
  ls -la "$dst"
'
----

[source,terminal]
----
total 1656
drwxr-sr-x.  2 1001140000 root          4096 Oct 21 16:36 .
drwxrwsr-x. 10 root       1001140000    4096 Oct 21 19:16 ..
-rw-r--r--.  1 1001140000 root       1682848 Oct 21 19:06 model.pkl
-rw-r--r--.  1 1001140000 root           597 Oct 21 19:06 training_metadata.json
----

The timestamp and size can differ. `model.pkl` and `training_metadata.json` must both be listed.

The running predictor loads `/mnt/models/anomaly-detector` (`--model_dir=/mnt/models/anomaly-detector`). Copy the same `model.pkl` there so the restart in the last step picks it up:

[source,terminal]
----
oc exec -n self-healing-platform self-healing-workbench-0 -c self-healing-workbench -- bash -c '
  set -euo pipefail
  mkdir -p /mnt/models/anomaly-detector
  cp -a /mnt/models/parasol-anomaly-detector/model.pkl /mnt/models/anomaly-detector/model.pkl
  ls -la /mnt/models/anomaly-detector
'
----

== Step 2: Upload to MinIO

Use this object store:

[cols="1,2"]
|===
| Setting | Value

| Endpoint
| `http://minio.parasol-insurance.svc.cluster.local:9000`

| Bucket
| `model-storage`

| Region
| `us-east-1`

| Object prefix
| `parasol-anomaly-detector/`
|===

The Showroom terminal does not have the `aws` CLI, so `./export/export-to-s3.sh` cannot run there. The workbench has `boto3` and can reach MinIO. Load the MinIO keys from the secret in your terminal, then upload. Leave the key values in the terminal.

[source,terminal]
----
export AWS_ACCESS_KEY_ID=$(oc get secret minio-root-user -n parasol-insurance -o jsonpath='{.data.MINIO_ROOT_USER}' | base64 -d)
export AWS_SECRET_ACCESS_KEY=$(oc get secret minio-root-user -n parasol-insurance -o jsonpath='{.data.MINIO_ROOT_PASSWORD}' | base64 -d)
----

[source,terminal]
----
oc exec -i -n self-healing-platform self-healing-workbench-0 -c self-healing-workbench -- \
  env AWS_ACCESS_KEY_ID="$AWS_ACCESS_KEY_ID" AWS_SECRET_ACCESS_KEY="$AWS_SECRET_ACCESS_KEY" python3 - <<'PY'
import os
from pathlib import Path
import boto3
from botocore.client import Config

src = Path("/mnt/models/parasol-anomaly-detector")
bucket = "model-storage"
prefix = "parasol-anomaly-detector"
s3 = boto3.client(
    "s3",
    endpoint_url="http://minio.parasol-insurance.svc.cluster.local:9000",
    aws_access_key_id=os.environ["AWS_ACCESS_KEY_ID"],
    aws_secret_access_key=os.environ["AWS_SECRET_ACCESS_KEY"],
    region_name="us-east-1",
    config=Config(signature_version="s3v4", s3={"addressing_style": "path"}),
)
try:
    s3.create_bucket(Bucket=bucket)
    print(f"created {bucket}")
except Exception as exc:
    code = exc.response.get("Error", {}).get("Code", "") if hasattr(exc, "response") else ""
    if code in {"BucketAlreadyOwnedByYou", "BucketAlreadyExists"}:
        print(f"bucket {bucket} already exists")
    else:
        raise
for path in sorted(p for p in src.iterdir() if p.is_file()):
    key = f"{prefix}/{path.name}"
    s3.upload_file(str(path), bucket, key)
    print(f"uploaded s3://{bucket}/{key} ({path.stat().st_size} bytes)")
PY
----

The first upload prints:

[source,terminal]
----
created model-storage
uploaded s3://model-storage/parasol-anomaly-detector/model.pkl (1682848 bytes)
uploaded s3://model-storage/parasol-anomaly-detector/training_metadata.json (597 bytes)
----

A second run prints `bucket model-storage already exists` and uploads the same two objects again. That is success. The byte counts can differ after another training run.

== Restart the Predictor

After the copy and the upload, tell KServe to load the model from `/mnt/models/anomaly-detector`:

[source,terminal]
----
oc rollout restart deployment \
  -l serving.kserve.io/inferenceservice=anomaly-detector \
  -n self-healing-platform
----

[source,terminal]
----
deployment.apps/anomaly-detector-predictor restarted
----

Verify:

[source,terminal]
----
oc get inferenceservice anomaly-detector -n self-healing-platform
----

[source,terminal]
----
NAME               URL                                                                         READY   PREV   LATEST   PREVROLLEDOUTREVISION   LATESTREADYREVISION   AGE
anomaly-detector   http://anomaly-detector-predictor.self-healing-platform.svc.cluster.local   True                                                                  22h
----

`AGE` will not match. `READY` should be `True`. Empty `PREV` and `LATEST` columns are normal for this InferenceService.
